# Q1 Upgrade Implementation Plan (TRAM technique mapping: matcher + fusion)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the thesis evidence base into a journal-grade (Q1-target) study: fix the explainer, close every gap a Q1 reviewer will raise that can be closed with real experiments, and hand claude.ai (web chat) one package from which it can write the article without inventing numbers.

**Architecture:** Every new experiment is a pre-registered script under `_showcase/scripts/` that reads saved predictions or local weights through `ttpmap` (`src/ttpmap/`), writes one CSV to `_showcase/results/`, and registers its numbers in `thesis_numbers.json` via `scripts/build_numbers.py`. QA gates (`scripts/qa_gates.py`) refuse any document with an unregistered number. Work that needs a GPU stays in the existing Colab notebooks (00-10) and comes back through one ingest script.

**Tech Stack:** Python 3.13 `.venv` (torch 2.15 CPU, transformers 5.23, sentence-transformers, sklearn, pandas), Ollama (qwen2.5:7b, local), Google Colab T4 for GPU work.

**Spec:** this plan's "Q1 gap table" below plus `_showcase/GAP_REGISTER.md`, `_showcase/STATUS.yaml`, `_showcase/thesis_feed/DO_NOT_CLAIM.md`. The explainer fixes come from the fact-check of 2026-11-15 (8 findings).

## Global Constraints

- Tune on DEV only; TEST is evaluated once per pre-registered configuration.
- Uncertainty: paired / percentile bootstrap over test sentences, 10,000 resamples, `numpy.random.default_rng(20261114)`; exact McNemar; Holm within each new family.
- Fixed systems: SVM refit (deterministic); RoBERTa and SecBERT = mean probability of seeds 42-44; matcher = mean score of seeds 42-44; fusion = z-score sum, weights (3,1,1,1), order matcher, SVM, RoBERTa, SecBERT.
- Report seeds as mean +/- sd (ddof=1) over seeds; ensembles as a point value with a 95% CI. Never mix the two in one table row set without saying so.
- `thesis_numbers.json` is the single source of truth. No number in any document unless registered.
- Never overwrite run outputs or rater xlsx files; new results go to new files.
- No dataset sentence text in outputs beyond short excerpts (the upload packer refuses full sentences).
- Run Python as `E:\Osamas Paper\.venv\Scripts\python.exe -X utf8`.
- Pre-registration files are sealed (SHA-256 in `experiments/prereg/REGISTRY.csv`) before the script that reads test results runs.
- No git commit or push (author instruction, 15 Nov 2026, D25); results stay as files.

## Review Focus

1. Entity masking hides technique evidence: ATT&CK software names such as "PowerShell", "cmd", "at" are also technique evidence. Expected: names that occur in any technique name are never masked. Test in Task 3.
2. Sibling data contains TRAM dev/test sentences (the "procedure" sources are built from the same ATT&CK pages). Expected: exact and near duplicates (normalised text) of TRAM dev/test are removed before training, and the count removed is reported. Test in Task 5.
3. LLM returns ids outside the 733-label space, sub-technique ids in odd formats (`T1059/001`, `t1059.001`) or prose. Expected: ids are normalised to upper case `Txxxx.yyy`; anything not in the space is dropped; an empty answer counts as a miss; parse rate is reported. Test in Task 7.
4. Stacker sees test data during fitting or C selection. Expected: `fit_stacker` raises `LeakageError` unless `split == "dev"`. Test in Task 4.
5. Recomputed classifier probabilities differ from the saved ones (wrong tokenizer, wrong max length), so robustness drops are measured against the wrong baseline. Expected: clean-input probabilities match `test_probs.npy` within 1e-3 before any perturbation is scored. Test in Task 3.
