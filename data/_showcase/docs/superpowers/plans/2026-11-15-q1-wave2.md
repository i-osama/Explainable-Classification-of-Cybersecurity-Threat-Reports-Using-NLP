## Review Focus

1. Fused or component scores contain NaN or -inf for labels outside a component's space. Expected: NaN is treated as -inf in sets, ranks and margins; never a NaN threshold. Test: `test_conformal.py::test_nan_scores_never_in_set`.
2. Calibration rows with zero gold labels or a quantile index above n. Expected: zero-label rows are dropped with a count; `ceil((n+1)(1-alpha)) > n` returns an all-labels set (tau = -inf), not an index error. Test: `test_conformal.py::test_quantile_above_n_gives_full_set`.
3. Threshold fitted on test by mistake. Expected: `calibrate_threshold`, `calibrate_rank` and `dev_threshold_for_coverage` raise `LeakageError` unless `split == "dev"`. Tests in T3 and T4.
4. Ties in confidence when sweeping coverage. Expected: risk-coverage uses a stable sort (`kind="stable"`) so the curve is deterministic. Test: `test_selective.py::test_ties_deterministic`.
5. Revoked ATT&CK ids mapped twice or chains of revocations (A revoked by B, B revoked by C). Expected: follow `revoked-by` relationships to the final active id, cycle-safe. Test: `test_drift.py::test_revocation_chain`.
